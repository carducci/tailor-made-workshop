# Generated data

These CSVs are **generated** from `Architecture workbook.xlsx` by
`tools/export_workbook.py`. Do not hand-edit them - change the workbook (or the
export script) and regenerate. The workbook stays the source of truth.

- `weightings.csv` - every constraint's modifier against each capability
- `constraints_architectural.csv` - the technical constraint catalog (+ class)
- `constraints_team.csv` / `constraints_organizational.csv` / `constraints_environmental.csv` - the other three catalogs
- `style_recipes.csv` - which constraints make up each named style
